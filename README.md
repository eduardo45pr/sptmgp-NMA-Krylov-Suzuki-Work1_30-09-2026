 PauliVib — A Reproducible Software Workflow for Compact Pauli Analysis of Molecular Vibrational Hamiltonians

This repository contains the computational data, plotting scripts, publication figures, and manuscript source files associated with the research article:

> **A Reproducible Software Workflow for Compact Pauli Analysis of Molecular Vibrational Hamiltonians**

The repository is organized as a reproducibility package linking the numerical results reported in the manuscript to the corresponding plotting scripts and publication material.

---

## Overview

The workflow connects classical molecular normal-mode analysis (NMA) with compact quantum-compatible representations of vibrational Hamiltonians. The main computational stages are:

1. Molecular structure preparation and geometry optimization.
2. Cartesian Hessian construction.
3. Mass-weighted normal-mode analysis.
4. Construction of the vibrational Hamiltonian.
5. Power-of-two embedding.
6. Exact Pauli decomposition.
7. Numerical validation of Pauli reconstruction.
8. Controlled Pauli-term compression.
9. Spectral validation of compressed Hamiltonians.
10. Second-order Suzuki–Trotter validation.
11. Runtime and memory telemetry.
12. Extension to protein-scale systems through reduced modal subspaces.

The repository separates **raw/numerical results**, **plot-generation scripts**, **generated figures**, and **publication files** so that the provenance of the reported results can be followed directly.

## Directory description

### `Results/`

This directory contains the numerical data generated by the computational workflow and used to produce the scientific figures.

The CSV files provide the numerical provenance of the plots rather than requiring values to be extracted from published images.

Representative outputs include:

```text
<molecule>_Figure2_Pauli_validation_data.csv
<molecule>_Figure3_compression_diagnostics.csv
<molecule>_NMA_modes.csv
<molecule>_full_IR_corrected.csv
```

It also contains integrated and scalability datasets such as:

```text

FINAL_best_operating_point_similarity_ge_0.99.csv
FINAL_compression_frontier.csv
FINAL_integrated_summary.csv
Figure6_representation_scaling.csv

protein_telemetry_all.csv
```

### `Plots/`

This directory contains Python scripts for regenerating the principal figures directly from the numerical files stored in `Results/`.

Current plotting scripts include:


The intended data flow is:


### `Figures/`

This directory contains generated graphical outputs associated with the analysis and manuscript.

It includes molecular Pauli-reconstruction plots, compression diagnostics, Suzuki–Trotter validation, representation-scaling results, computational telemetry, and protein-scale analysis.

## Molecular benchmark systems

The molecular benchmark set associated with the study includes:

- Anatoxin-a
- Aflatoxin B1
- Saxitoxin
- Tetrodotoxin
- Ricinine
- Patulin
- Ochratoxin A
- Zearalenone
- T-2 toxin
- Citrinin

These systems provide chemically varied benchmarks for testing the numerical representation and validation workflow.

The molecular set is used for computational spectroscopy and Hamiltonian-representation testing. The repository does not provide synthesis, preparation, acquisition, or handling protocols for these compounds.
